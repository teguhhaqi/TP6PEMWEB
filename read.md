Jawaban Tugas Pendahuluan Modul 6

1. JavaScript dan Kegunaannya

JavaScript adalah bahasa pemrograman untuk membuat halaman web menjadi interaktif dan dinamis.

Kegunaan: Membuat animasi, menangani klik tombol, validasi form, dan menampilkan popup.

2. jQuery dan Kegunaannya

jQuery adalah library (kumpulan fungsi) JavaScript yang dibuat untuk mempermudah penulisan kode JavaScript.

Kegunaan: Mempercepat penulisan kode, mempermudah manipulasi elemen web, serta membuat animasi dan AJAX dengan lebih simpel.

3. Perbedaan JavaScript dan jQuery

JavaScript: Bahasa pemrograman dasar (native) yang berjalan di browser, kodenya cenderung lebih panjang.

jQuery: Library siap pakai berbasis JavaScript yang membuat kode jauh lebih singkat dan ringkas.
